# Advanced SEO + AI Visibility

A benchmark-driven GEO / AEO / AI visibility platform designed around:
- benchmark and ranking analysis
- SEO and AI-search content generation pipelines
- business entity and authority engineering
- 5-layer GEO / LLM visibility framework integration
- Markov-inspired content cluster analysis
- reporting and SQL persistence
- browser dashboard and API endpoints

## Quick start

```bash
python -m advanced_seo_ai_visibility.cli --output advanced_seo_ai_visibility/output
python -m advanced_seo_ai_visibility.app
```

Then open:
- http://localhost:5000/
- http://localhost:5000/api/report

## Included modules

- benchmark data and ranking engine
- keyword + FAQ + voice snippet generation
- prompt library for SEO and AI answer engines
- GEO framework model and metrics
- content-cluster authority logic
- database-backed report snapshots
- workflow automation and dashboard rendering
- REST JSON reporting endpoint

## Main KPI formula

`GRS = (ES × RR × SC × TV × CA × CP)`

Where:
- ES = Entity Strength
- RR = Retrieval Readiness
- SC = Semantic Completeness
- TV = Trust Vector
- CA = Citation Amplification
- CP = Conversational Persistence
